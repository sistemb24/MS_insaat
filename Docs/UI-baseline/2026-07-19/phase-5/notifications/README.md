# Faz 5 — Bildirimler görsel baz çizgisi

Üretim derlemesi, `demo-accounting` oturumu ve `/bildirimler` route'u ile kaydedildi.

- `desktop-notification-center.png`: 1440 × 1000 masaüstü çalışma alanı.
- `desktop-unread-filter.png`: Okunmamış filtresi seçili masaüstü durumu.
- `mobile-notification-center.png`: 390 × 844 mobil kırılım.

Kontrol kapsamı: AppShell v2, tek sayfa başlığı, gerçek bildirim sayaçları,
kategori tercihleri, birleşik arama, okunma filtresi, yeni/önceki bildirim ayrımı,
kaynak kayıt bağlantıları ve öncelik dağılımı. Mobil görünümde belge düzeyinde
yatay taşma `0` ölçüldü. Görsel doğrulama sırasında veri değiştiren işlem
gönderilmedi.
