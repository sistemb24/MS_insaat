# Faz 5 — Abonelik/Paketler görsel baz çizgisi

Üretim derlemesi, `demo-accounting` oturumu ve `/abonelik` route'u ile kaydedildi.

- `desktop-subscription.png`: 1440 × 1000 mevcut yıllık paket görünümü.
- `desktop-monthly-plans.png`: Aylık dönem seçili paket karşılaştırması.
- `mobile-subscription.png`: 390 × 844 mobil kırılım.

Kontrol kapsamı: AppShell v2, tek sayfa başlığı, sandbox ödeme sınırı, mevcut
paket ve yenileme özeti, dört paket kartı, erişim matrisi, ek özellikler, ödeme
geçmişi ve ödeme sağlayıcı olayları. Mobil görünümde belge düzeyinde yatay taşma
`0` ölçüldü. Görsel doğrulama sırasında satın alma, yenileme veya ödeme mutasyonu
gönderilmedi.
